## 在国外怎么看优酷？

在播放视频的设备上连接番茄，再进入优酷正片，按下面四步操作：

1. 从[番茄回国加速器官网](https://www.fanqiejsq.com/)下载对应的 Windows、macOS、iOS 或 Android 客户端。

3. 手机端完全退出优酷后重开；电脑端关闭原播放页，再进入[优酷官网](https://www.youku.com/)。
4. 搜索想看的节目，选择正片和具体集数播放，观看期间保持番茄连接。

## 手机优酷地区限制怎么解决？

苹果和安卓手机都应先在本机连接番茄，再重开优酷。通过番茄官网选择 iOS 或 Android 版本，按系统提示完成连接授权；切回优酷时确认番茄仍在连接。不要只从播放器退到首页，应退出 App 后重新搜索作品并选择集数。

## 电脑优酷地域限制怎么解除？

在电脑安装并连接番茄 Windows 或 macOS 客户端，再重新打开优酷网页或桌面客户端。手机上的连接不会自动覆盖电脑。网页依然显示旧提示时，关闭原标签页，从优酷首页重新搜索节目；如果网页黑屏而客户端正常，可先用客户端观看。

## 在国外看优酷上的电影为什么有的看不了？

不同电影和剧集的地区范围、付费方式可能不同。连接回国线路后，重新打开受限作品的正片；若其他作品能播而它仍失败，查看是否提示会员、单片付费、下架或尚未上线，按这个具体提示处理，不必为一部电影反复更换所有设置。
