1. 已安装叭嗒的用户直接使用原客户端；需要安装时，从设备的正规应用商店查找开发者为 iQiYi 的“爱奇艺叭嗒”。应用商店是否在当地提供下载，以实际页面为准；不要从不明网站取得安装包。

## 爱奇艺叭嗒国外地区限制怎么办？看作品提示，不看首页

叭嗒同时提供漫画阅读和动画播放：[叭嗒隐私政策](https://bud.m.iqiyi.com/ulink/bdprivateh5)将两者列为基本功能。首页能打开，并不能证明某一章漫画或某一集动画在当前地区可用。先分别记录出问题的是**漫画章节**还是**动画集数**，再按上述步骤重开同一内容；若多个作品和首页都打不开，也检查设备本地网络。

[爱奇艺 FUN 会员服务协议](https://bud.m.iqiyi.com/ulink/funmemberagreement)明确，部分会员动画与漫画因版权地域限制仅限中国大陆观看或阅读。作品若明确提示当前地区不提供，应以该作品页面及平台现时说明为准；不要把网络重试当成获得海外播放权。

## 开通爱奇艺 VIP 就有叭嗒 FUN 会员吗？

**不能直接等同。**FUN 会员和普通爱奇艺 VIP、体育会员等是不同的会员产品。FUN 会员面向动画、漫画等权益，不能凭它观看爱奇艺的电视剧、综艺、电影等其他付费内容；部分漫画章节或动画还可能另有付费条件。遇到“请开通会员”时，先核对目标内容要求的会员类型、当前登录账号和该内容页面的权益说明，再决定是否购买。更换线路不会增加账号权益。

如果是在 iPhone 上以**游客方式**购买 FUN 会员，官方协议说明权益仅绑定购买设备，换设备使用前应先按叭嗒页面指引绑定注册账号。已付款却看不到权益时，先核对是否仍在原购买设备及原账号，不要重复下单。

## 已下载漫画或动画，出国后一定能看吗？

不能保证。爱奇艺的 FUN 协议写明，作品下线时，即使内容此前已下载或缓存到本地，也可能无法继续阅读或观看。遇到已缓存内容打不开，先查目标作品是否下线或权益发生变化，不要只反复清理缓存、切换线路。

## 漫画图片加载慢、动画播放卡，先查哪一层？

用**同一作品**做对照：如果其他网站也慢，先切换本地 Wi-Fi 与移动数据；如果仅叭嗒的图片逐张加载慢或动画转圈，保持同一账号和内容，切换一次番茄的可用影音线路，再退出叭嗒重试。只有一部作品异常时，也可能是该作品或叭嗒服务侧的问题。这里是排查顺序，不代表任何固定速度或一定恢复播放。
