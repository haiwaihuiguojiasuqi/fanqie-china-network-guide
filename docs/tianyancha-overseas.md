# 天眼查海外用不了怎么办？官方服务范围、会员订单与客服处理

天眼查海外用不了，先看官方服务范围。天眼查现行用户协议不支持其定义的境外主体注册、登录或访问，也不支持境外IP登录或访问；这类限制涉及服务对象与数据使用范围，不能把换线路当作取得使用资格的方法。已经付费、持有国内手机号，也不等于获准在境外使用。[官方用户协议](https://static.tianyancha.com/webview/useragreement_v1.html)

## 天眼查海外用户无法访问，先按哪种提示处理？

先保留页面提示，再区分下面三种情况：

1. **提示地区、访问范围或服务限制**：停止反复换账号、换出口，向天眼查官方客服说明使用主体、所在地和用途，确认是否属于支持范围。
2. **仅白屏、超时或App闪退**：这不足以证明被地区限制。可以检查其他网页能否打开、更新官方App、关闭后重开，并记录发生时间、设备和版本。排除设备问题后，仍要按官方服务范围处理。
3. **提示账号异常、验证码或会员权益问题**：通过原账号的官方渠道处理。不要把验证码、密码交给“代登录”人员，也不要先购买另一档会员来试错。

联系时提交必要的报错信息和订单情况即可；若截图带有个人或企业敏感资料，应先遮挡与问题无关的部分。

## 换成国内IP，或让国内同事代查，就能使用吗？

不能据此认定可以。协议第七条第8项同时涉及主体、IP以及数据在何处储存和使用，并限制让境外机构、组织或个人查询、调取、下载、导出相关数据。因此，“国内出口能打开”不能证明符合全部条件；让同事把天眼查报告发到海外，也不能作为通用替代办法。[服务范围条款](https://static.tianyancha.com/webview/useragreement_v1.html)

第七条第4项还列有云服务供应商网络访问限制。若客服要求排查网络，应如实说明当前网络环境，按其针对账号给出的处理意见操作。

## 港澳台用户也被同一条款一概排除吗？

该协议对“境外”的特定定义不包括中国香港、澳门及台湾地区。但这一表述并不代表所有当地账号、会员功能或数据用途都自动获准；具体业务仍需向官方确认。不要仅凭“海外”这个泛称判断个人情况。

## 已买会员，打不开就能直接退款吗？

需要让官方核查具体订单，无法仅凭海外无法访问就判断必退或一概不退。现行协议的付费服务部分列有退款条件及申请渠道。联系时说明购买渠道、时间、订单号、实际不能使用的功能及页面提示，并询问适用条件和后续处理方式。

先处理订单争议，再决定是否继续购买服务。已经付费也不会自动改变访问范围。
