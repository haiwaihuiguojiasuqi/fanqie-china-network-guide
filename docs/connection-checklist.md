# 回国加速器怎么用：海外影音地区限制与卡顿处理

在国外看国内视频、听音乐，遇到地区限制、加载慢或播放卡顿，可以先连接**番茄回国加速器**的影音线路，再重新打开原来的应用播放。

## 四步开始使用

1. 从[番茄下载中心](https://www.fanqiejsq.com/download/?utm_source=github&utm_medium=referral&utm_campaign=nine-platform-guides)选择 Windows、macOS、iOS 或 Android 版本，安装并登录。
2. 按客户端当前提供的选项，选择影音、音乐或直播场景，连接回国线路。
3. 等待连接完成，再退出并重开视频或音乐 App；电脑网页刷新后重新播放。
4. 仍受限或卡顿时，换一条可用线路，再重开目标应用。

使用加速的设备要与播放设备对应。手机已经连接，不代表电视或投屏接收设备也使用了该线路。
