# 国外怎么看nba回放？找整场录像、精简版和赛后集锦

如果在国外打开国内体育平台的 NBA 回放时收到地区限制提示，这条视频可能没有向当地开放播放。可在观看设备上连接番茄回国加速器的影音或直播线路，重开平台，再打开原场次的回放试播。使用 NBA 官方 League Pass 的读者，可以直接从赛程页找回放，下文也列出了美国和加拿大的上线时间。

## 国内体育平台的 NBA 回放提示地区限制怎么办？

1. 从[番茄回国加速器官网](https://www.fanqiejsq.com/)下载观看设备对应的版本，安装并登录。
2. 在客户端选择适合影音或直播的线路并连接。用电脑看就在电脑上连接，用手机看就在手机上连接。
3. 关闭原网页或退出 App，重新进入比赛详情。用对阵双方和比赛日期确认场次，再选择整场回放或对应单节。
4. 地区提示仍在，可以退出播放器，换一条同类线路再试。如果赛后页面只列集锦，或整场条目显示需要会员，按该场页面核对视频入口和观看条件。[腾讯体育回放和会员排查](https://github.com/haiwaihuiguojiasuqi/fanqie-china-network-guide/blob/main/docs/tencent-sports.md)

## NBA 官方哪里能找到整场录像？

如果所在地区支持 NBA League Pass，使用有有效订阅的 NBA ID 登录 [NBA 赛程页](https://www.nba.com/games)或 NBA App 的 **Games**。按日期和对阵选比赛，打开比赛详情，选择整场录像。手机 App 可以先点 **Watch Now**，再选要看的转播版本。[NBA 官方回放入口说明](https://support.watch.nba.com/hc/en-us/articles/360011802673-Full-Game-Replays-and-Condensed-Game-Availability)

只想补看关键回合，可以在同一场次找 **Condensed Game**。它是缩短后的比赛剪辑。想快速了解结果和亮点，可以看官方视频页的 **Game Recaps**。如果连哪支队赢了都想先保密，优先从赛程页进。[NBA 官方集锦](https://www.nba.com/watch/featured)

## 比赛已经结束，为什么还找不到整场回放？

NBA 官方说明，赛后剪辑和上传可能需要数小时。若这场比赛的直播在 League Pass 受转播权限制，整场录像还可能有额外的等待时间。

- **美国全国转播受限的比赛**通常到比赛次日美东时间早上 6 点开放整场回放。
- **美国当地转播受限的比赛**通常在比赛结束 3 天后开放整场回放。
- **加拿大全国转播受限的比赛**通常在直播结束几小时后开放回放。

这几项时间适用于 NBA 官方 League Pass，查具体赛事及特殊赛段可看官方说明。如果已经过了适用的上线时间，先核对 NBA ID 的订阅状态和对阵日期，再用比赛详情反馈给 NBA 支持。[NBA 地区转播限制指南](https://support.watch.nba.com/hc/en-us/articles/115002481154-League-Pass-Blackout-Guide)

## 看录像前怎么隐藏比分？

在 NBA App 的 **Games** 页或账户偏好中打开 **Hide Scores**。电脑上也可以在赛程页日期旁打开这个开关。首页新闻和集锦标题仍可能写出结果，可以收藏赛程页，下次从那里直接查比赛。[NBA 隐藏比分说明](https://support.watch.nba.com/hc/en-us/articles/115000587174-Hide-Scores)
