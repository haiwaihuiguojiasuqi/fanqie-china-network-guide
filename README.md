## 影音播放问题：先根据现象选择下一步

| 你看到的现象 | 先做什么 | 观察什么 |
| --- | --- | --- |
| 页面一直加载，多段内容都卡 | 对照同设备的其他网页，再按[连接检查步骤](docs/connection-checklist.md)测试 | 是本地网络普遍异常，还是某个服务异常 |
| 只有一集、一首歌或一场赛事无法播放 | 保留内容名称、集数、版本与提示原文 | 是否涉及单独的内容范围或权益 |
| 提示登录、开通会员或购买 | 核对当前账号及该内容的权益页面 | 是否登录了购买时使用的账号 |
| 明确提示所在地区不提供服务 | 查看对应平台说明或联系平台支持 | 平台是否为所在地提供该内容 |
| 手机能用，电脑或电视不能用 | 用同一内容逐一对照设备和入口 | 问题是否只发生在某个客户端或播放方式 |

这张表用于缩小问题范围；仅凭“连上后能播放”或“换网络后仍失败”，都不足以判断全部原因。

## 海外回国加速器适合什么时候使用？

如果本地网络正常、账号和内容资格已经确认，但连接国内服务时仍频繁缓冲，可以尝试回国线路，并对照连接前后的表现。测试时固定设备、同一段内容和清晰度，每次只改变一个条件，避免把降画质的效果误认为线路改善。

连接国服游戏时，可按游戏专题比较同一设备、相近时段下的延迟波动和掉线情况；如果主要是设备发热、画面掉帧，应同时检查设备负载和画质设置。

番茄加速器的[官方产品说明](https://www.fanqiejsq.com/)将服务定位为网络连接优化，并提供 Windows、macOS、Android 与 iOS 下载入口。平台会员、内容授权与可用地区仍由各平台决定；具体设备要求和功能以当前下载页为准。

## 如何开始

1. 在影音或游戏表中选择对应专题，先确认应用、官方入口及具体提示。
2. 影音问题可配合[影音连接检查与对照记录](docs/connection-checklist.md)处理；游戏问题按对应游戏专题完成客户端、账号区服和线路检查。
3. 问题仍存在时，将设备、客户端版本、发生时间、内容名称或游戏区服及提示原文提供给对应客服。账号订单问题找平台或游戏官方；线路连接问题可从番茄官网查找支持入口。
