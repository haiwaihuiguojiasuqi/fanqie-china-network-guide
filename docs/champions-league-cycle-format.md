# 欧洲冠军联赛几年一次？赛季、联赛阶段与淘汰赛怎么区分

欧洲冠军联赛每年举行一届，按跨年的足球赛季组织；“2026/27赛季”是一届比赛，不是2026年和2027年各一届。一个赛季包含不同阶段和许多比赛日，不能把一场决赛或一个比赛日当成整届赛事。

## 欧洲冠军杯几年一次？

如果这里的“欧洲冠军杯”指现在的欧洲冠军联赛，答案同样是每年一届。欧足联的[2026/27赛季说明](https://www.uefa.com/uefachampionsleague/news/02a6-20d57cfcd03e-407c22a7f465-1000--2026-27-champions-league-teams-dates-draws-format-final/)将其称为原欧洲冠军杯沿革下的赛事，并以2026/27、2027/28等赛季衔接。

查赛程时，先确认赛事全名是 UEFA Champions League，以及页面标注的赛季，再找目标球队或比赛阶段，避免把其他名称相近的赛事混在一起。

## 为什么同一个赛季要从一年踢到下一年？

因为资格赛、联赛阶段和淘汰赛分布在不同月份。欧足联于2026年10月12日更新的赛季说明列出：2026/27届从2026年7月7日开始，决赛计划在2027年6月5日举行。赛程可能调整，应以当期官方比赛页为准。

只想追某支球队时，直接到[欧足联官方比赛页](https://www.uefa.com/uefachampionsleague/fixtures-results/)确认赛季、对阵、比赛日期和时间。不要只搜“今年欧冠决赛”，否则容易点进上一届结果或另一届预告。

## 联赛阶段还按四队小组踢六场吗？

现行2026/27规则采用36队统一排名的联赛阶段。根据[欧足联竞赛规程第17条](https://documents.uefa.com/r/Regulations-of-the-UEFA-Champions-League-2026/27/Article-17-Match-system-league-phase-Online)，每队对阵8个不同对手，共8场，其中4场主场、4场客场。

这不意味着36队彼此全部交手，也不是同组3个对手各踢两场。阅读老文章时，要先看它对应的赛季；2024/25起引入的新赛制，不能与此前的小组赛表混用。

## 前八名、附加赛和十六强是什么关系？

联赛阶段结束后，排名第1至8位直接进入十六强；第9至24位进入淘汰赛附加赛；第25至36位出局。附加赛用于决定剩余十六强名额，并不是下一届欧冠的资格赛。

因此“已经进入联赛阶段”和“已经进入十六强”不是同一件事。追赛时按官方页面的阶段标签查找，避免漏掉需要踢附加赛的球队。

## 海外追赛怎样避免看错日期或直播入口？

先核对官方对阵页的时区和日期，再到所在地或目标平台的当期授权转播页确认是否提供这场比赛。赛事赛程存在，不代表某个视频平台一定拥有该地区的播放权。
