# cctv5海外直播回放怎么看？按节目单找回看和重播

如果在国外打开 CCTV-5 的回看时看到地区限制提示，这段节目可能没有向当地开放播放。可以在实际观看的设备上连接番茄回国加速器的影音或直播线路，再重开浏览器或 App，回到原来的节目条目试播。

## 有「回看」按钮，但提示地区限制，怎么连接？

1. 在观看设备打开[番茄回国加速器官网](https://www.fanqiejsq.com/)，下载对应版本，安装后登录。
2. 在客户端选择适用于影音或直播的线路并连接。用电脑浏览器看，就在电脑上连接。
3. 关闭原播放页或退出观看 App，再重新打开。回到原节目单的日期和时段，点同一个「回看」条目。
4. 如果提示没变，可以切换一条同类线路，再重开播放器重试一次。节目单没有「回看」入口时，可以用下面的办法找重播排期或赛事回放。

## 在国外怎样按播出时间找到 CCTV-5 回看？

打开央视网的[体育节目单](https://sports.cctv.com/epg/)，选 CCTV-5 和节目播出时的北京时间日期，找到对应时段，看到「回看」就点进去。找前几天的节目，可以从「查询往日节目单」进入。

日期按央视播出时间来选。比如节目在北京时间周六凌晨播出，即使你当地还是周五晚上，节目单也应选择周六。找不到比赛时，再核对原来的转播频道。CCTV-5、CCTV-5+ 和 CCTV-16 各有节目单，选错频道会错过对应条目。

## 节目单只列了重播，或赛事页只有集锦，怎么看？

- **节目单列着即将播出的「实况录像」**。记下它的频道和北京时间，如果节目安排在 CCTV-5，到点可从[央视网 CCTV-5 频道页](https://tv.cctv.com/live/cctv5/)看重播。赛后回看则要看原播出条目是否提供入口。
- **想找特定比赛而手头没有播出时间**。到[央视网赛事中心](https://cbs.sports.cctv.com/schedule_tabs.html)按比赛日期或队名找赛程，再看该场是否有视频入口。遇到「集锦/回放」合并标记，进去看视频标题和时长。看到「实况录像」时，可以对照标题、时长和节目说明，判断它是否包含整场比赛。
- **赛事只显示图文或数据**。可以回节目单查之后是否安排重播。若赛事属于[央视体育VIP](https://vip.sports.cctv.com/course)，以该赛事页面的播放入口为准，平台说明部分赛事因版权原因仅提供直播。
