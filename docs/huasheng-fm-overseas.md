# 花生fm在国外打不开怎么办？旧端已停服，先到佛山+找节目

花生FM旧客户端和“花生台”小程序已经停止运营，人在国外打不开时，应先改用佛山+中的“花生”板块寻找节目。佛山市新闻传媒中心的[停服与权益迁移公告](https://content.foshanplus.com/newsDetails.html?memberId=2111063&newsId=1004482)明确，旧端于 **2026年3月1日00:00** 停止所有运营服务；回国线路不能让已停服的旧端重新提供服务。

## 现在怎样继续听原来的广播和节目？

1. 到应用市场查找“佛山Plus”或“佛山plus”，核对开发者为佛山市新闻传媒中心。iPhone 可从[佛山Plus官方 App Store 条目](https://apps.apple.com/tw/app/%E4%BD%9B%E5%B1%B1plus-%E7%88%B1%E4%BD%9B%E5%B1%B1%E5%B0%B1%E4%B8%8A%E4%BD%9B%E5%B1%B1/id1380586193)辨认应用；能否安装以自己设备的商店页面为准。
2. 打开或更新佛山+，在当前客户端查找“花生”板块。官方[花生板块介绍](https://www.fsonline.com.cn/FS_PLUS/998517.html)给出了广播、回听和节目互动入口。
3. 按原节目的名称、频率和播出日期查找。收听正在播出的广播与找某一期回听是两件事；进入同一频率，不代表已经找到那一期节目。
4. 找不到旧节目时，先向佛山+反馈节目名称和日期；不要把“核心功能迁入”理解为所有历史节目都一定保留、都已向所有账号开放。

佛山Plus当前官方应用介绍仍列有花生FM板块；不要用旧安装包的存在判断服务是否仍在运营。

## 佛山+能进，单个节目仍有地区提示怎么办？

先确认提示来自佛山+中的原节目，而不是旧花生FM客户端。如果新端具体音频提示地区限制、无法播放，可以在收听设备上尝试番茄回国线路：

1. 从[番茄回国加速器下载中心](https://www.fanqiejsq.com/download/)进入对应系统页面，按说明安装并登录。
2. 在当前客户端选择可用的音乐或影音场景、适用回国线路，等待连接成功。
3. 退出原节目播放页面，重新进入佛山+的同一个音频或同一频率比较提示。
4. 地区提示仍相同时，换另一条可用线路，再重开同一内容；把节目链接和完整提示交给客服继续排查。

这些步骤用于新端的网络播放问题，不能补回失效的旧账户权益，也不能保证每个节目获得新的地区授权。若没有地区提示，而是整个平台打不开，先检查本地网络；若只有某一期不在列表中，先核对该内容是否仍由平台提供。

## 旧账户积分、花生币和已购音频现在还能迁移吗？

先看自己是否已经办理过迁移。原公告安排了手动迁移，并对积分、花生币及通过花生币购买的VIP音频专辑作了说明，不能把它概括为所有新旧会员都自动互通。

**公告中的权益保留期限是2026年5月31日，现在已经过期。** 公告说明，逾期未办理的原账户迁移权益会失效。已经迁移的，登录当时接收权益的佛山+账户核对；没有迁移或记录有疑问的，向佛山+官方反馈原账户和订单情况，不能再把年初的迁移步骤当成今天仍有效的办理承诺。

## 已迁移，为什么仍然找不到原来购买的内容？

先核对佛山+当前登录的账号，检查是否正是当时迁移到的目标账号，再按专辑名称查找。准备好原订单、专辑名称和迁移记录，通过佛山+当前反馈入口询问具体内容与账号的对应关系。

这类问题应核对账号和历史交易；不要为了找旧权益反复新建账号或重新购买同一专辑。官方旧公告描述的特定已购音频权益，也不能扩展成对所有新增内容的免费收听承诺。

## 网上的旧版教程和收听红包活动还能照着做吗？

旧教程里的客户端名称、按钮、补登期限和活动规则要分别看时间。先使用佛山+当前提供的入口找节目；年初页面中的收听分钟数、抽红包次数等活动介绍，不能直接当作今天仍在执行的权益。应用商店列出的功能更新，也不证明某个账号已经迁移成功或某个海外节目已恢复播放。
