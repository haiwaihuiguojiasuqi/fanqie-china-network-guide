# 国外怎么听qq音乐：地区限制、歌曲变灰的解决方法

在国外听QQ音乐遇到地区限制，可能是当前海外网络位置不在歌曲的播放范围内；歌曲一直转圈、播放断续则可能与跨境连接有关。可以先连接**番茄回国加速器的影音回国线路**，再退出并重新打开QQ音乐，重播想听的歌曲。

## 用番茄连接QQ音乐，按这四步操作

1. 打开[番茄回国加速器官网](https://www.fanqiejsq.com/)，下载适合手机或电脑的版本并安装。
2. 登录番茄，选择客户端当前提供的影音回国线路并连接，等待连接完成。
3. 完全退出QQ音乐后重新打开，进入原来的歌单，点击不能播放的歌曲；电脑网页用户刷新歌曲页面。
4. 听歌期间保持番茄连接。若仍有地区提示或加载慢，换一条可用影音线路，再重开QQ音乐重试。

## 歌曲变灰、没有音源是什么情况？

<img src="../assets/errors/qq-music-no-source.png" alt="QQ音乐歌曲弹窗提示暂时没有音源呢" width="420">

图中显示“暂时没有音源呢”，没有明确写地区限制；这类提示还可能与具体歌曲版本有关。

连接后只有一首歌不能播放时，在[QQ音乐](https://y.qq.com/)搜索同一首歌的其他版本；若多首歌都断续，降低音质、暂停后台下载，或切换 Wi-Fi 与移动网络。更多连接操作见[连接与排查清单](./connection-checklist.md)。

## 能播放，为什么下载不了？

先看歌曲是否下载完成、设备空间是否充足，再按页面提示选择可下载的音质。番茄不替代QQ音乐会员或付费歌曲购买。

若换线路后仍失败，可把歌曲链接、报错截图和设备系统发给番茄客服，方便继续处理连接问题。
