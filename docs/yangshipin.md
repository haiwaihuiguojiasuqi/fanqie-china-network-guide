# 在国外如何看央视频？地区限制与无法播放解决方法

央视频在国外怎么看？遇到“暂不对您所在地区提供服务”，通常与网络位置和节目的播放地区范围有关；如果频道直播转圈、频繁缓冲，则可能是跨境连接不稳定。可以先连接番茄回国加速器的影音回国线路，再重新打开央视频播放。

## 连接番茄后重新打开央视频

1. 进入[番茄回国加速器官网](https://www.fanqiejsq.com/)，下载手机或电脑对应版本，安装并登录。
2. 选择客户端当前提供的影音、直播场景或适用回国线路，等待连接完成。
3. 完全退出央视频 App 后重开；网页观看则关闭原页面，重新进入[央视频官网](https://www.yangshipin.cn/)。
4. 搜索要看的频道或节目，重新播放。仍然缓冲时，切换另一条可用回国线路，并适当降低清晰度。

## 直播、回放和投屏分别怎么处理？

- **找不到直播：**进入目标频道或赛事页，查看当天节目安排和开播时间，按页面时区换算当地时间。预告、精彩片段和正在直播的内容要分开查找。
- **要看 CCTV5：**在央视频中搜索对应频道；CCTV-5 与 CCTV-5+ 的节目安排不同，更多入口见[CCTV5 观看方法](./cctv5.md)。
- **手机能看，投屏失败：**先确认手机与电视处于同一局域网，并检查接收设备。手机连接番茄后，电视不一定使用同一条回国线路。

若节目要求会员或单独购买，仍需使用具备对应权益的账号。
