# 网易云一起听国外受限怎么办？好友能听、自己没声音时怎么排查

网易云音乐「一起听」时，如果海外一方收到地区限制提示，这首歌可能仅在部分地区获得播放授权。可以先在收到提示的设备上连接番茄回国加速器的音乐或影音线路，重开网易云音乐，再试同一首歌。

## 怎样重连后和好友恢复一起听？

1. 在无法播放的设备退出一起听，再完全退出网易云音乐。从[番茄回国加速器官网](https://www.fanqiejsq.com/)下载适合该设备的客户端，安装并登录。
2. 在番茄选择当前客户端提供的音乐或回国影音线路并连接。然后重开网易云音乐，先点开刚才那首歌对应的专辑，单独试播同一个版本。
3. 两边都能单独听同一个版本时，请好友从播放页的一起听入口发一次新邀请。接受后，留在应用内确认两边的播放进度有没有一起走。
4. 仍出现地区提示时，可以换一条可用线路并重开应用，对照同一个版本。如果提示仍在，先从同一歌单挑一首两边都能播的歌继续听。

## 好友能听，为什么我进去了还是没声音？

先让双方分别播放同一个歌曲版本。歌名一样也可能是不同专辑、现场版或重制版，可以让好友发歌曲详情页供你核对。如果你单独试听也收到地区限制或会员提示，先按你自己收到的提示处理，好友那边能播放只能说明他这一侧可用。

若两边单独都能播，而加入后只有一边没声音，先检查媒体音量和音频输出设备，例如是否还连着蓝牙耳机。离开后再用新邀请进一次，观察是没有进入共同播放，还是进度在走却没有声音。

## 邀请打不开，怎么确认是入口还是歌曲的问题？

请好友先用一首两边都能播的歌重新发起邀请，然后在手机的网易云音乐客户端里打开。如果只在聊天软件内打开了链接预览，试着切回网易云音乐继续操作。双方都更新到商店里可用的版本后，可由另一方发起一次，看看问题是否只发生在一个发起账号或一台设备。
