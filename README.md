## 怎么使用番茄？

1. 下载适合手机或电脑的番茄客户端，安装并登录。
2. 选择影音、音乐、直播或对应游戏场景，连接回国线路。
3. 连接后重开目标应用；仍有地区提示或卡顿时，换一条线路再试。

影音内容需要会员或单独购买时，仍需对应平台的账号权益。游戏延迟问题按游戏专题处理。
