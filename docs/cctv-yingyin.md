# 国外如何看央视影音？海外节目与直播的地区提示怎么处理

在海外打开央视影音，若节目或直播提示所在区域无法观看，通常是这项内容的播出授权有地域范围。可以先在播放设备连接**番茄回国加速器的影音或直播回国线路**，完全退出央视影音，再打开原节目或频道重试。

## 国外怎么看央视影音？先按这四步操作

1. 在正在观看的手机或电脑上，从[番茄回国加速器下载中心](https://www.fanqiejsq.com/download/)安装对应客户端并登录。
2. 在番茄当前客户端选择影音、直播场景或适用的回国线路，等待显示连接成功。
3. 完全退出央视影音，再打开刚才受限的节目或直播频道，不要只刷新留在原报错页的播放器。
4. 如果仍是相同的地区提示，换一条可用线路，退出央视影音后重开同一内容，比较提示是否变化。

电脑端需要安装央视影音时，可从[央视影音官方页面](https://cbox.cntv.cn/)查找下载入口；已经安装的用户直接从连接步骤开始。

## 为什么有些节目能看，有些电视剧、电影或赛事不能看？

在已能打开客户端的情况下，能否观看仍要看具体节目的播出授权与当前提示。如果某个节目受限，原因可能是该节目的授权范围没有覆盖当前地区；这与客户端能否启动是两件事。

先看**具体节目**的提示，不要把一个内容的播放结果推断到整个央视影音。[央视网 2020 年的央视影音 PC 版帮助](https://help.cctv.com/2020/07/15/ARTIOj86vYdL6EkyZhYQDpj0200715.shtml)说明，部分内容只获中国大陆地区播出授权，部分 CCTV-5 比赛场次也受地域性版权限制。这是当时 PC 版的规则说明，不代表今天所有设备和节目的安排。一段新闻能播放，不代表另一部电视剧、电影或比赛也能播放。

如果原节目提示所在地区不提供服务，可按上面的番茄线路步骤尝试；如果换线后出现的是内容下架、账号或单独付费提示，就要按新提示处理。回国线路不能增加节目版权或账号权益。

## 在国外如何看央视影音直播？

先在播放设备连接番茄的影音或直播回国线路，重开央视影音，再进入目标频道的**直播入口**。若看到节目预告，先核对频道节目表与当地时间；若比赛已经结束，再查该场次是否提供回放。直播频道、点播节目和回放是不同入口，某个入口没有目标内容时，不要据此判断整个平台不可用。

CCTV-5 赛事尤其要看当场比赛的实际版权范围。上述央视影音 PC 版帮助说明，部分场次不能向非大陆地区提供赛事信号；连接线路也不保证每场比赛都能恢复播放。

## 手机与电脑上的央视影音地区提示，处理方式一样吗？

核心步骤相同：**在哪台设备播放，就在哪台设备建立回国连接**。手机或电脑出现节目地区提示时，在实际播放的设备连接番茄，再完全退出央视影音并重开原节目。手机上的番茄连接不会自动改变另一台电脑的网络；电脑已连接，也不会让手机自动走同一条线路。手机切换 Wi-Fi 与移动网络后若再次看到地区提示，先查看番茄是否仍连接，再退出央视影音并重开原内容。

电脑端可以通过央视影音官方页面获取客户端。若应用本身打不开，先确认普通网页能否打开并检查客户端更新；能打开应用、只有某个节目提示地区限制时，再针对该节目换线。

## 提示所在地区不能看，或换线后仍不能播放，怎么办？

若应用能打开、只有节目提示地区不可看，先考虑该内容的授权范围；若连应用首页都打不开，先按上一节检查本地网络和客户端。这里切换的是番茄网络线路，不能在央视影音里直接改掉节目的版权授权。记录完整提示和节目名称，确认番茄仍显示已连接，换另一条可用影音或直播线路后彻底重开央视影音。同一节目仍提示地区受限时，把节目链接、频道、设备系统、所在地区和报错截图发给番茄客服检查线路；也可按央视网帮助中心的联系入口咨询内容的播出范围。

若只有一场赛事或一部剧失败，而其他内容能播放，应优先看这项内容自己的版权与服务提示。央视影音、央视频和央视网网页播放器是不同入口，排查时要确认自己实际打开的是哪一个。

## 海外看央视影音一定免费吗？

不要根据“可以下载客户端”推断每项节目都免费。遇到购买、会员或单独付费页面时，以当前内容页显示的权益和价格为准；番茄回国线路与央视影音内容权益是两项服务。如果打开的是央视网网页播放器，应按网页入口排查；以上客户端步骤针对央视影音。
