# 蜻蜓会员出国能用吗？原账号、小说购买与缓存失效排查

在国外用蜻蜓FM听会员节目，如果原集数提示地区限制，可以先在听书设备连接番茄回国加速器的国内影音线路，再重开这一集。地区提示与节目的授权和访问范围有关；回国线路用于排查网络地区因素，不能把不在会员范围内的小说变成免费内容。

## 会员节目有地区提示，怎样连接后重试？

1. 在实际听书的手机或平板上，从[番茄下载中心](https://www.fanqiejsq.com/download/)安装对应客户端并登录。
2. 选择当前客户端提供的影音、音乐或适用音频场景，连接回国线路。只在另一台设备上连接，不会自动改变听书设备的线路。
3. 完全退出蜻蜓FM后重新打开，使用原账号进入刚才失败的同一个专辑、同一集，比较提示是否改变。
4. 仍提示地区限制时，换一条可用线路，再重开原集数。若变成要求购买、登录验证或内容下架，就转到对应的问题处理。

能否在国外收听，要看这一个节目、当前账号权益和实际提示。会员身份不能替代具体节目的播放资格；另一档电台能播，也不能证明整本付费小说都能播。

## 有VIP，为什么有声小说仍要求单独购买？

先看该专辑当前是否标明会员可听，以及失败的是全本还是其中某集。将“会员畅听的小说”和“账号单独买过的小说”分开核对，别只凭VIP标记再次付款。

官网可查的[《蜻蜓FM超级会员服务协议》](https://sss.qingting.fm/qt-agreement/super-member-20190724.html)标注更新及生效日期为2021年2月4日。第四部分第9款把会员内容、额外付费专辑及其他收费服务分开说明，会员之外的内容可能仍需单独购买；部分单购内容也有自己的使用期限。

处理时打开当前专辑和原账号的消费记录，核对是否购买了这一版本、这一集，以及页面写明的期限。当前可听范围应看实际订单和专辑说明。换线不会延长会员，也不能替你购买未包含的作品。

## 明明付过会员费，登录后为什么仍显示没有权益？

先把支付记录和蜻蜓FM内的账号信息对应起来。确认当前登录方式、账号、会员服务名称及有效期，与购买时是否一致；付款成功只能证明有这笔支付，不能单独证明当前打开的账号已经获得这项服务。

上述协议第三部分说明，登录会员账号后可查询已开通服务、期限和消费记录。若付款记录与应用内状态不一致，保留订单号、购买时间、会员名称和应用提示，从[官方应用页面](https://apps.apple.com/cn/app/id506685538)列出的反馈渠道或应用内帮助联系平台核对。不要为了验证账号而反复充值，也不要把验证码或完整支付资料贴在公开评论里。

## 以前不登录也能听，换手机后为什么记录没了？

先保留原设备，确认旧设备当时是登录账号还是游客模式，再查看旧设备上的收藏、下载与收听记录。不要先清空应用数据或重装来找回记录。

2021版协议第三部分第4款对游客模式专门作了说明：游客只能体验部分业务，卸载、重装或更换设备后，相关数据可能清空且无法恢复。这与已登录账号的会员记录不是同一回事。该说明不能当作当前每个版本都仍有相同游客入口，也不代表换一个登录方式就会自动合并旧记录。

如果原设备还能打开，先记录能够辨认账号和内容的信息，再请平台核对。会员订单异常应查订单，游客本地记录缺失则应说明原设备和使用状态，两种问题不要混成“出国后会员失效”。

## 下载过的小说还在，为什么登录后仍不能继续听？

先确认下载是否完成、登录的是否为原账号，并查看原集数提示的是会员到期、需购买还是版权不可用。保留现有下载，不要先删除再试着重下。

2021版协议第三部分第4款提到，本地下载或缓存的内容，在版权授权期限届满后可能不可查看；第四部分也说明内容有相应的收听和下载服务期限。因此，缓存还在不等于它永远不受权益或授权变化影响。反过来，也不能把某一集失效推断成所有离线内容都不能用。

对当前这一集，把专辑链接、集数、原账号订单和完整提示交给平台核对。地区提示可以按前述番茄线路重试；明确要求购买或显示授权已结束时，换线不能替代对应处理。

## 手机能用会员，换到电脑或另一设备为什么不一样？

先核对是否使用同一账号、同一专辑版本，再看目标设备当前支持的服务。上述协议第四部分说明软件版本、系统和终端不同，实际服务可能有差异，不宜把手机结果直接套到电脑或车机上。

遇到设备或登录数量提示，以当前应用提示和官方答复为准。普通网络连接和单集地区提示可参看[蜻蜓海外听书指南](qingting-fm.md)。
