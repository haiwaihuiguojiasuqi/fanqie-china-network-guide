# 企鹅fm在日本用不了怎么办？已停运，先找官方已购入口

企鹅FM旧服务已于2023年9月6日0时停止运营。在日本打不开旧App，先按停运后的内容去向处理，不能直接认定为地区限制；番茄回国线路也不能重启已经关闭的服务。想继续听以前买过的专辑，应从企鹅FM官网公告进入“已购内容页面”。

## 以前买的专辑现在从哪里找？

先打开[企鹅FM官方下线公告](https://fm.qq.com/offline/dist/static/pages/announcement.html)，点其中的[已购内容页面](https://fm.qq.com/offline/dist/purchased.html)，按页面提示选择原来购买时使用的账号类型并登录，再找对应专辑。

入口目前展示QQ登录选项；另一账号入口提示复制链接到PC浏览器访问。遇到这个提示时，换电脑浏览器打开同一官方链接，再按页面提供的方式登录。不要因为旧App打不开就重新注册一个账号，购买记录需要和原账号对应。

官方公告将已购内容作为停运后的单独访问安排，但这不等于新账号可以免费领取旧专辑。登录后找不到内容时，先核对购买账号和订单中的专辑名称；页面能打开，也不能单凭这一点确认某张专辑已经能够完整播放。

## 换到泰国或其他国家，还需要反复换回国线路吗？

停运涉及旧服务本身，并非只针对日本。在泰国或其他海外地区遇到旧App无法使用，也应先走官网的已购入口。反复安装旧版本、清理缓存或换线路，都不能让已关闭的注册、充值和旧内容服务恢复。

如果官方已购页面可以打开、原账号也已登录，只有具体音频出现地区提示或持续加载，可以尝试调整收听设备的网络：

1. 从[番茄回国加速器官网](https://www.fanqiejsq.com/)下载适合设备的客户端，安装并登录。
2. 选择当前客户端提供的音乐或影音场景，连接回国线路。
3. 重新打开浏览器中的官方已购页面，使用原账号进入专辑，再试同一集。
4. 仍然加载失败时，切换另一条可用回国线路后重开页面；若提示账号、订单或内容不存在，则回到相应问题处理。

线路调整是对具体页面连接问题的尝试，不会补回账号没有购买的专辑，也不会改变停运安排。其他播放故障可参考[连接检查](connection-checklist.md)。

## 原创录音、收藏和收听历史还能一起找回吗？

这些内容与已购专辑的处理不同。官方公告要求用户在停运前通过PC端保存原创录音，并说明停运后关闭录音下载；收藏、收听历史等个人资料也列在停运后清理的范围中。

现在不要把仍能看到一个旧下载链接理解为录音仍可恢复。先检查自己以前保存到电脑、手机或个人备份中的文件；没有备份时，本文没有能够重新取回旧录音或历史记录的办法。

## 金豆兑换和懒人听书VIP月卡现在还能领吗？

公告里的金豆兑换和VIP月卡领取属于停运前安排，截止点是2023年9月6日0时，不能当作现在仍有效的福利。公告所列客服QQ也注明仅在2023年12月31日前有效，不宜把这个旧号码当成当前处理入口。

如果你当时已完成兑换，应去接收权益的平台核对原账号记录。不要为了“补领”向陌生人提供密码、验证码或付费购买所谓恢复资格。继续寻找节目的其他合法发行渠道时，应以该平台实际提供的专辑与权益为准，不能推断企鹅FM订单自动通用。
