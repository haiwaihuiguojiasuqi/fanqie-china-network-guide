# 海外怎么看cctv5？地区限制与体育直播卡顿解决方法

在海外打开 CCTV5 提示“所在地区暂不支持播放”，通常与当前网络位置和节目的播放地区范围有关；直播一直转圈、断续缓冲，可能与跨境连接不稳定有关。先用番茄回国加速器连接影音回国线路，再重开 CCTV5 播放页或观看 App。

## 用番茄连接后重新播放

1. 从[番茄回国加速器官网](https://www.fanqiejsq.com/)下载手机或电脑对应版本，安装并登录。
2. 选择客户端当前提供的影音、直播场景或适用回国线路，完成连接。
3. 关闭原来的央视网播放页，重新打开[CCTV-5 官方直播](https://tv.cctv.com/live/cctv5/)；使用央视频或央视影音的用户，完全退出 App 后重开。
4. 进入目标频道播放。若仍卡顿，切换另一条可用回国线路，再降低一档清晰度。

截图提示“您所在的地区，暂不支持播放该视频”，实际选中的是 **CCTV-5+ 体育赛事频道**。CCTV-5 与 CCTV-5+ 是两个频道，连接后要返回原来的频道重新播放。

## 找不到比赛或连接后仍有问题

- **频道能看，但不是目标比赛：**查看[央视体育节目单](https://sports.cctv.com/epg/?channel=cctv5)，核对比赛日期、频道和开播时间。按节目单时区换算当地时间，注意跨日。
- **想看整场回放：**在对应赛事或栏目页查找回放，精彩片段与完整比赛不是同一个入口。
- **地区提示没有消失：**换一条可用线路并重启播放器；仍失败时，把频道、节目链接和报错发给番茄客服。

央视频与央视影音是不同 App；使用央视频的操作可看[央视频海外播放方法](./yangshipin.md)。
