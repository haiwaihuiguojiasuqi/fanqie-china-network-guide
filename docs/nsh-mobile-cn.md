2. 在要运行游戏的同一部手机，进入[番茄客户端下载中心](https://www.fanqiejsq.com/download/)选择 iOS 或 Android 版本，按该系统页面说明安装并登录。在当前客户端选择适合国服游戏的可用回国线路并完成连接。
3. 完全退出游戏，再重新打开并使用原来的登录方式进入原区服。先看是否能完成更新和登录，再进入实际玩法观察操作响应。若要换线，先退出当前对局，在番茄客户端改选另一条可用线路后重开游戏，尽量在同一设备和本地网络下比较。
