# 海外怎么看 CCTV5：直播入口、节目单和回放排查

在国外看 CCTV5，先确认目标比赛是否安排在 CCTV-5 体育频道，再进入官方播放页并核对所在地区的观看条件。找不到比赛、直播转圈和版权提示是不同问题，应分别检查。番茄回国加速器可用于优化国内服务的网络连接，不能决定频道播什么，也不能代替内容授权。

本文由番茄回国加速器维护，适合希望观看体育直播、查询节目或寻找回放的海外华人。

## CCTV5、CCTV5+ 和央视频有什么区别？

CCTV-5 是体育频道，CCTV-5+ 是另一个体育赛事频道；两者的节目安排需要分别查看。[央视网官方直播页](https://tv.cctv.com/live/cctv5/)分别列出了这两个频道，并提供央视影音客户端入口。

央视频是另一个观看平台，央视影音是应用名称，都不能直接当作 CCTV5 的同义词。反馈“CCTV5 海外无法观看”时，说明自己是在央视网页面、央视影音还是央视频中播放，才能准确定位问题。央视频的操作见[央视频海外使用指南](./yangshipin.md)。

## 按这四步找到正确直播

1. 打开[央视体育节目单](https://sports.cctv.com/epg/?channel=cctv5)，选定频道及比赛日期，核对赛事名称和播出时间。节目可能调整，以临近开播时的官方安排为准。
2. 检查页面标注的时区，再换算为所在地时间。若安排使用北京时间，还要考虑当地夏令时以及日期跨日，避免提前一天或晚一天寻找直播。
3. 进入[CCTV-5 官方直播页](https://tv.cctv.com/live/cctv5/)，确认频道名称。正在播放其他节目时，回到节目单核对，不要先判断为网络故障。
4. 阅读播放器提示。若说明某节目因版权或地区原因不可播放，核对官方服务范围，或寻找所在地获授权的转播入口。

## 画面卡顿时怎么检查？

先记录卡顿发生时间，比较同一设备上的其他普通视频。如果所有视频都缓冲，先检查 Wi-Fi、移动网络或同时运行的下载；如果只有这个直播异常，再测试当前应用或浏览器是否更新，并重新打开播放页。

需要优化国内连接时，从[番茄回国加速器官网](https://www.fanqiejsq.com/)下载适合设备的版本，按客户端现有的影音场景或线路连接，再重开官方播放器。保持同一频道和清晰度，对比连接前后的缓冲情况；具体操作见[连接检查清单](./connection-checklist.md)。

## CCTV5 海外直播回放怎么找？

先在节目单中选择实际播出日期，查看是否有回看入口，也可以从对应赛事或栏目页寻找完整节目。区分实况录像、整场回放、新闻报道和精彩片段，搜索结果中的短视频未必是整场比赛。

某次直播可看，不代表其回放一定存在或具有相同的可用范围。若页面只有集锦或提示内容不可用，继续核对节目说明；更换网络不能让尚未提供的回放出现。向平台反馈时带上频道、节目名称、日期、使用入口和错误提示，比只描述“海外看不了”更便于处理。
